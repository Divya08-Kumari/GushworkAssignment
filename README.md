# Gushwork Assignment

A modern and fully responsive SaaS landing page that follows the design and structure of Gushwork created using only HTML, CSS, and JavaScript without the use of any framework.

## Features

* Responsive design on desktops, tablets, and mobile devices
* Sticky header with scroll direction detection
* Interactive images slider with draggable images and swipe support
* Image edge-aware zoom preview
* Scroll animation using IntersectionObserver API
* Keyboard navigation with proper ARIA labeling
* Animated mobile burger menu
* Form field email validation with visual feedback
* Modern UI designs including gradient, blob animation, and marquee effect

## Technologies

* HTML5
* CSS3
* Pure JavaScript

## Project Highlights

* Modularity in JavaScript code
* Semantic and accessible markup structure
* Layout using Flexbox & CSS Grid
* Enhanced performance through optimized transitions and animations
* Built-in JavaScript and no third-party library included

## Responsive Design Breakpoint

* Desktop: > 1024px
* Tablet: Between 768px & 1024px
* Mobile: < 768px
